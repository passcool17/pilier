# Pilier

Copie GitHub Pages de l'app **Pilier** (séances d'haltères pour deux gabarits, dos protégé), faite à l'origine avec Grok Build.

En ligne : https://passcool17.github.io/pilier/

- Les fichiers sont la version compilée de l'app d'origine, adaptée pour vivre sous `/pilier/`.
- `manifest.webmanifest` et `sw.js` permettent de l'installer comme app (Android et iPhone) et de l'utiliser hors ligne.
- La voix du coach utilise des fichiers `audio/*.mp3` déjà enregistrés ; la reconnaissance vocale utilise celle du navigateur (Chrome Android, Safari).
- Les données (journal, poids, profil) restent dans le téléphone (localStorage).
